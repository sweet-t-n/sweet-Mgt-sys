# 🍰 Sweet Management System

**Language:** Java | **Paradigm:** OOP 

A **comprehensive dessert management system** to streamline sweet sales, orders, and user interactions.  
Supports **role-based access** for Admins, Store Owners, Raw Material Suppliers, and general Users.  

---

## 🛠 Admin Features
- 👥 **User Management:** Manage store owners & raw material suppliers accounts.  
- 📊 **Monitoring & Reporting:** Track profits, generate financial reports, and identify best-selling products.  
- 🌍 **Statistics:** Display registered users by city.  
- 📝 **Content Management:** Handle recipes, posts, and user feedback.  

## 🏪 Store Owners & Suppliers Features
- 🍫 **Product Management:** Add, update, remove products, monitor sales, and implement dynamic discounts.  
- ✉️ **Communication:** Messaging system; optional email notifications for special requests.  
- 🗂 **Account Management:** Update business information.  
- 🛒 **Order Management:** Process and track orders efficiently.  

## 👩‍💻 Beneficiary Users Features
- 🔑 **User Account:** Sign up, log in, manage personal account, and post/share dessert creations.  
- 🔍 **Explore & Purchase:** Browse recipes, filter by dietary needs/allergies, purchase directly.  
- 💬 **Communication & Feedback:** Contact store owners/suppliers and provide feedback.  

## 🖥 Interface
- Supports **GUI** or **Command-Line Interface (CLI)**  
- Role-based dashboards: Admin, User, Store Owner, Raw Material Supplier  
- Sample CLI: Login prompt for username/password with access to respective dashboards

- 💻 Object-Oriented Programming (OOP) in Java  
- 🎯 Designing role-based systems & CRUD operations  
- 🧠 Problem-solving, teamwork, and managing complex requirements
